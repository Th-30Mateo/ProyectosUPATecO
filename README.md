# Ejercicios de Python

Repositorio personal de ejercicios y programas de consola desarrollados durante el aprendizaje de Python.

Los ejercicios están organizados en el directorio `ProyectosUPATecO/` y cubren operaciones matemáticas, generación de valores aleatorios y administración básica de registros.

## Índice de ejercicios

### 1. Calculadora básica

**Archivo:** [`Calculadora.PY`](ProyectosUPATecO/Calculadora.PY)

Calculadora interactiva que permite realizar:

- Suma.
- Resta.
- Multiplicación.
- División.

Incluye un menú de opciones y una comprobación para evitar la división por cero durante el uso de la opción correspondiente.

### 2. Dado digital

**Archivo:** [`DadoDigital.PY`](ProyectosUPATecO/DadoDigital.PY)

Simulación de un dado de seis caras mediante generación de números aleatorios.

Permite:

- Realizar tiradas.
- Contabilizar la cantidad total de tiradas.
- Registrar cuántas veces salió cada número.
- Mostrar un resumen al finalizar.

### 3. Sistema de gestión de usuarios

**Archivo:** [`SisGestionDeUsr.PY`](ProyectosUPATecO/SisGestionDeUsr.PY)

Programa de consola para practicar la gestión de registros de usuarios.

Incluye operaciones para crear, consultar, editar y eliminar registros, además de asignación de roles y generación de usuarios de ejemplo.

Los datos se mantienen en memoria durante la ejecución.

### 4. Sistema de gestión veterinaria

**Archivo:** [`SisGestionVeterinaria.PY`](ProyectosUPATecO/SisGestionVeterinaria.PY)

Ejercicio orientado a la administración de información relacionada con una veterinaria.

Consultá el archivo fuente para revisar las operaciones y opciones disponibles en la versión actual.

## Requisitos

- Python 3.
- Terminal o consola.
- No se requieren dependencias externas para los ejercicios cuyos imports utilizan exclusivamente la biblioteca estándar.

## Ejecución

Cloná el repositorio:

```bash
git clone https://github.com/Th-30Mateo/proyectoNuevo.py.git
cd proyectoNuevo.py
```

Ejecutá cada ejercicio por separado desde la raíz:

```bash
python ProyectosUPATecO/Calculadora.PY
```

Para ejecutar otro ejercicio, reemplazá la ruta por la del archivo correspondiente.

En Linux o WSL, utilizá `python3` si ese es el comando disponible en tu entorno.
